# Rover Control Program (Lab 5)

## Purpose
This C++ program simulates a Mars rover control system that prompts the user for a command and battery level, displays a status report, and executes specific rover actions (such as capturing panoramas, collecting rock samples, transmitting data, or returning to base).

## How to Run the Program
1. Open your terminal in the repository folder.
2. Compile the C++ program using a compiler like g++:
   ```bash
   g++ lab5.cpp -o lab5

Run the compiled executable:
​On Windows: ./lab5.exe
